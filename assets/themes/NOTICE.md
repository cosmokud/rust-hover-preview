# Bundled theme assets

Both files in this directory are TextMate themes (`.tmTheme`) generated from the
VS Code themes named below. Only the color definitions were carried over; the
conversion moved each theme's `colors` and `tokenColors` entries into the
`settings` array a `.tmTheme` uses, and nothing else was changed.

## Atom One Light — `atom-one-light.tmTheme`

- Source: https://github.com/akamud/vscode-theme-onelight (`themes/OneLight.json`)
- Author: Mahmoud Ali, port of Atom's One Light syntax theme
- License: MIT

## One Dark Pro — `one-dark-pro.tmTheme`

- Source: https://github.com/Binaryify/OneDark-Pro (`themes/OneDark-Pro.json`, v3.20.2)
- Author: zhuangtongfa (Binaryify)
