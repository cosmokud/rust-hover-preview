# Security Policy

## Supported versions

Only the latest release is supported with security updates. If you are on an
older version, please update to the latest release first.

| Version | Supported          |
| ------- | ------------------ |
| Latest release | :white_check_mark: |
| Older releases | :x:                |

## Reporting a vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, open a
[private security advisory](https://github.com/cosmokud/rust-hover-preview/security/advisories/new)
or contact the maintainers through a GitHub issue asking for a private contact
channel, without including details of the vulnerability.

Include as much of the following as you can:

- A description of the vulnerability and what it affects.
- Steps to reproduce the issue.
- The app version and your Windows version.
- Any logs, screenshots, or proof-of-concept details that help.

You will receive a response acknowledging your report. If the issue is
confirmed, a fix will be prepared and released as soon as possible. Please do
not disclose the issue publicly until a fix is available.

Thank you for helping keep this project and its users safe.
